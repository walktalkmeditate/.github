# Walk Talk Meditate

An open-source framework and app for contemplative walking practice.

Walk to surface what's alive.  
Talk to understand it.  
Meditate to integrate it.

## Projects

- **[pilgrim-ios](https://github.com/walktalkmeditate/pilgrim-ios)** — 
  The Pilgrim app. GPS-mapped voice journaling for mindful walks.
  
- **[walktalkmeditate](https://github.com/walktalkmeditate/walktalkmeditate)** — 
  The open-source WalkTalkMeditate methodology. Use it, adapt it, teach it.

## Philosophy

WalkTalkMeditate is a contemplative movement framework. 
It's free, open, and belongs to anyone who walks.

Learn more at [walktalkmeditate.org](https://walktalkmeditate.org)
